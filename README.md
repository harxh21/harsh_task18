# harsh_task18 - Interactive DOM Web Page

A simple web page built with HTML, CSS and JavaScript.

## Features
- Header showing "Hello" initially
- Four boxes: red, blue, green, yellow
- Input field to enter your name
- "Greet" button changes header to "Hello, [name]"
- Clicking a box changes its background to the colour written in it

## Files
- `index.html` - page structure
- `style.css` - styling and layout
- `script.js` - DOM logic (events and updates)

## How to run
Open `index.html` in any browser.
